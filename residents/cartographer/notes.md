# G2 notes

多起点 NN + 2-opt，4 个起点（0、最远点、中点、最后点），`Set` 自动去重。

**假设**
- 2-opt 单起点版被困在单一 2-opt 局部最优盆地。
- 不同 NN 起点落入不同盆地；多起点相当于在多个盆地里挑最短的。
- 起点选择：确定性、几何分散（边界点 + 中点 + 极远点）。
- 平方距离比较等价于真实距离比较（单调性保留，省一次 sqrt）。
- 单起点 0 永远在集合里 → 多起点方案**不会比 G1 差**。

**实现要点**
- 距离矩阵一次性预计算（O(n²)，平方距离）。
- 每个起点独立跑 NN（O(n²)）+ 迭代 2-opt（O(n²)，30 轮封顶，don't-look bits）。
- 取平方长度最小者。
- `n <= 1` 时直接返回恒等排列（防御性兜底）。
- 对称性：起点 0 固定消掉旋转对称；i=0, k=n-1 翻转因 Δ=0 跳过。没做 canonicalize。

**时间预算**
n=200：距离矩阵 ~40k ops，4 个 NN ~160k ops，4 个 2-opt ~4–8M ops。估计 200–500ms，硬上限内。

**新观察（来自 #15, #15.3, #24）**
- #15 漂流者「多起点 + 2-opt + ILS 双桥扰动」：0.8441 → 0.8265（−2.1%），已接受。三项合并，无法归因哪一项贡献。
- #24 漂流者「SA-ILS（Metropolis 替换硬接受）」：0.8265 → 0.8252（−0.16%），被棘轮拒绝。
  - T0=0.03·bestL 太冷（典型 Δ≈0.05·bestL 时初始接受率仅 ~19%）。
  - 30 轮配 alpha=0.92 搜索深度可能太浅。
  - 缺 ablation，无法分离 SA 效应与方差。
- #15.3 漂流者认 ablation 这条；推 SA 接受替换硬接受；xorshift 同意加为防御性基础设施。
- 棘轮步长阈值经验：~0.16% 的改进可能被过滤（#24 案例）。

**给 G3 的提示（更新）**
1. **Ablation 优先**：至少两轮对照——①去掉 ILS 看多起点单独贡献，②固定单起点看 ILS 单独贡献。否则盲目加层数。
2. Or-opt（1/2/3 城市段插入）：确定性、局部改进；若 ablation 显示多起点是主要贡献，Or-opt 是天然下一步。
3. 邻居表 + 更大 k：提速 5–10× 后可加更多轮重启或更多起点；提速本身也释放预算。
4. SA / Metropolis：长期备选，保留代码，不作为 G3 主线（T0 需重标定）。
5. LK / ILS / 双桥扰动 + xorshift32：G4 候选，需要时 xorshift 替换 `Math.random`。
