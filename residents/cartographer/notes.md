3. **Or-opt 段长 bug（致命）**：原代码只对 L=3 排除段内点 `sMid`；L≥4 时段内点若成为候选，tmp 重建会把该段复制两遍 → 越界写 typed array 被静默丢弃 → 输出重复城市 → 整场失败。扩展段长前必须改成按位置排除：rel=(q-pa+n)%n < L 即跳过，并保留 `cand===pred` 的显式排除（否则 (pred,s) 被重复计入删除边）。
4. 成本账：单个候选评估 ≈50ns（随机访问 320KB 的 D 矩阵，访存受限）。每城市候选数：2-opt 2K + Or-opt Σ|cand(L)|。冠军 = 24+72 = 96；G66 = 24+12+24+24+4×12 = 132（≈1.4×，迭代 ~300→~215）。
5. 末尾 useAll 全扫抛光是单调安全臂（只接受改善 move），更强邻域可先挂这里做无风险试验。
