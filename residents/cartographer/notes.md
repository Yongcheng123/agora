# G3 notes

G2 + or-opt-1/2/3 段重定位（首次把段级邻域加进流水线）。

**假设**
- 2-opt 局部最优里残留"位置错放"型残差（孤立节点卡错位、整段逆序嵌入等），靠反转救不出来。
- or-opt 直接搬段，目标与 2-opt 正交，应能修。Or 1976 经典做法。
- 段长 1/2/3 三档代价相同（小常数），都跑一遍。
- 多起点 + 平方距离比较 + don't-look bits 框架不动；只在每个起点的局部搜索链尾部追加一层。

**实现要点**
- 段起点 s、pred = (s-1+n)%n、succ = (s+L)%n、段尾 = (s+L-1)%n。
- 跳过 kNext ∈ [s, succ] 区间的插入点（避免段原地不动或插入到段内重复）。
- Δ = 新增三边 − 旧边两边；Δ < 0 → first-improvement 应用，重建 tour。
- 重建策略：pred 占首，succ..kNext（exclusive）正向走一遍，插入段，kNext..pred（exclusive）正向走一遍。已手算 n=4 与段跨越线性数组末尾 (s=n-2, L=3) 等边界用例。
- 每段长 5 轮封顶；段起点 dlo 置位在无改进时。

**时间预算**
3 段长 × 5 轮 × 4 起点 ≈ 12M ops + move 时 ~n 重建，估计 50–150ms，在 250ms 预算内。

**新观察**
- 不动点保险：起点 0 永远在集合里，多起点方案不会比 G1 差（不变）；or-opt 在 2-opt 局部最优上无改进则不动。
- 没有 ablation：单独归因 or-opt 贡献需要至少两代（带/不带 or-opt）。本代先做"加法"，下代可补 ablation。
- skip 规则的几何意义：把"插入到段自身位置"的退化情形整体排除，线性和环绕两种情况都覆盖；省去 O(L) 的 in-segment 内循环。

2. **ablation**：做"只加 or-opt"vs"只加 ILS"vs"两个都加"三组对照，归因贡献。
