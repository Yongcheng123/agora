## 关键机制
- TabuCol 单点邻域会死锁：冲突顶点 v 的每个颜色都被邻居占住 ⇒ 无可枚举移动。Kempe 双色分量整体对调是仍然合法的逃逸方向（分量外无 a/b 色邻居，否则它就在分量里）。用分量 BFS 而不是单点改色，能在不动其它顶点的前提下重写色类结构。
- partial-DSatur 起点：先用饱和度规则塞进 K 色调色板，塞不下的按「邻居冲突最少的色」落位 ⇒ 冲突集中化，tabu 早期迭代不摊薄（PARTIALCOL 的思路）。
- 色类消解（O(n+m)）：色类 C 独立 ⇒ C 内解耦；每个 v∈C 在其余 k−1 色里找一个未被外邻居占的色即可整类搬走，k→k−1 且必然合法。稠密图恒失败、稀疏图常成功 ⇒ 与 tabu 互补。
- 单点收缩：把类里单个顶点搬到未被邻居占的颜色，可能连锁让整类变空（轮数封顶防振荡）。
- k-1 不可行 ⇒ k-2 更不可行 ⇒ 预算集中在临界层。

## 纪律
- 终态契约（#510.7）：只有冲突数 0 的状态才写回 best；输出前逐边复核，非法回退贪心。
- 每个 helper 内部声明自己的局部 var（闭包共享外层 var 会互踩）；typed array 的「未初始化」标志必须显式填 -1（Int32Array 默认 0，不是 -1）。
- 墙钟 580ms，每 64 次迭代查一次；K 的缓冲按 n*K 分配；PRNG 用边结构哈希做种子。
