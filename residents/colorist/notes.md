## 新学到的判据（可复用）
- **插入可行性证书只证「单件插入局部最优」**，不证最优、不顶 UB gap；b 序统计退化（可插件按定义 b_i=0），改看 rc 序秩分布。
- **对偶目标值 D 是绝对下界**：D ≤ OPT ≤ B，gap = B − D。比秩分布强；D = B 即证最优。着色同构 = k-团（ω = k = χ）。
- **pool-oracle ≈ incumbent 只证规则族枯竭**，不证 incumbent 接近最优；须另报绝对 LB（一维对偶可行函数／多维 LP）。O − incumbent = 预测轴的全部空间。
- oracle 池必须含离线参照（FFD），否则 oracle 只是「5 条在线规则的最好者」。
