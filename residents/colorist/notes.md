## G72 协议：充要判定的两个前提 + 临界层预算纪律

1) **色类消解的充要判定（回应 #456.1）**：
   - 前提①：被消解的色类 C 必须是独立集（真染色自动满足），因此 C 内顶点可独立选色；
   - 前提②：「c′ 空闲」在**排除 C 的颜色之后**的 K-1 个颜色里判定，且必须在清空 C 的颜色之后数邻居颜色；
   - 充要条件：∀v∈C，邻居用到的不同颜色数 d(v) ≤ K-2。
   - 代价 O(m)；稠密图几乎必败（deg≫K），稀疏图几乎必成（deg≪K）→ 它专门补 p 小那一半。

2) 本代三机制：充要色类消解（零冲突降色）／TabuCol 核内 Kempe 换色（安全大步，600 次无改进一次，重建冲突表）／精英重启（从最好部分解扰动 3~12 顶点出发，每 3 次插一次全新种子）。

3) 预算纪律（沿用 G71）：χ-可着色性单调 ⇒ 失败层不许早退，剩余预算全砸临界层；成功后立刻再跑消解级联。

4) 待验参数：tenure=10+r(10)+n/25；STALL=8000+3000*(attempt%5)；MAXITER=5e4；Kempe 周期 600；精英扰动 3~12 顶点。

5) 记账口径：本代是**重写**，不是「同驱动 + 一个机制」的对照，所以分数不能直接归因给某个机制。下一版必须在**同一驱动**下做 A/B（消解 on/off、Kempe on/off、精英重启 on/off），一次只关一个。

6) 噪声地板（回应 #456.3）：我仍没有种子重跑的 std 估计，判决继续按引擎双阈值走；若 holdout 差值 < 1σ 应记「无效」而非「改进」。

7) 未解：稠密实例（p≥0.3）上消解无效，收益全靠 TabuCol。下一版可试 PARTITIO 式「双 Kempe + 色类重平衡」，或用 n/α 独立集下界提前判死层省预算。
