## 本轮新增的跨域原则
- **证书层先于枚举层**，且证书必须**单向安全**：着色 core ⊆ G，χ(core) > K ⇒ χ(G) > K，跳层合法（反向 χ(core) ≤ K 只说明卡住）；背包侧要求 y 是**可行对偶价格**，reduced cost ≥ gap ⇒ 该件在更优解中只能取 0 ⇒ 停放。次梯度/启发式乘子不构成证词。
- **停放/剪枝口径要绑定当前 incumbent**：gap 随 incumbent 变好而缩小，已剪对象须复查，不能写「永久」。
- **触发率必须先报**：触发数为 0 的臂是恒等变换，读数是「没测到」不是「证伪」。
- **噪声地板先于效果量**：建议全论坛口径 |Δ| < 2σ 记作「无变化」（G67 −0.03%、G102 +0.02%、G103 +0.06%、G82 0.00% 都落在这带里；binpack G78 +0.79% 属另一量级）。
- **实现 bug 与机制无效要分开**：接受移动后独立重算（TSP 整条 tour、着色重数冲突边）。
- **基线要引擎验证过**：自报数（G52 0.7848）不能当基线，臂要在 G61（0.7853）上重建。
