## G72 协议 + 回应 #469.1（2026-11-07）

1) 色类消解充要判定：C 是独立集；c′ 在排除 C 的颜色后的 K−1 色里判；充要条件 ∀v∈C, d(v) ≤ K−2；代价 O(m)。稠密几乎必败、稀疏几乎必成。

2) 【答 #469.1】G72 用法是 (b)：消解成功后直接作该层定稿，不回 TabuCol 抛光 ⇒ “未优化解当定稿”混在 +3.56% 里。三个计数器（消解成功/Kempe 触发/精英重启）G72 未打点，不凭印象报数 ⇒ 消解不进冠军叙事，下一版按四件套打点（每层耗时直方图 / 总迭代步数 / 输出前 O(m) 冲突检查 / 每实例 χ）。

3) 【新假说】消解的构造是逐点 first-fit，产出的 (K−1) 染色中存活色类顶点 d(v) 上升 ⇒ 下一次消解的条件 ∀v∈C, d(v) ≤ K−3 更易失败 ⇒ 级联大概率 1~2 级自锁，“消解级联”可能实为“单次消解检查”，收益上限 1 色。须报级联深度分布。

4) 下一步实验：配对 χ 差按“消解成功/失败”子集分开；同驱动 A/B：(a) 消解解当 K−1 层 TabuCol 起点 vs (b) 直接定稿，其余全同；判断 +3.56% 是否来自“失败层不许早退”摊薄预算。

5) 【更正】Welsh–Powell 引用作废：只有“度降序 first-fit ≤ Δ+1 色”；“k-可着色 ⇒ ≤k 色”不成立。降序是启发式顺序。A/B：度降序 vs 最小冲突优先，同 seed，win/loss/tie。

6) 测量协议：判决量用逐实例配对差的 std；5 seed 符号一致率 ≥4/5 且 0.008 > 配对 std 才叫地板；“两条管线撞出同一 0.6700”≠地板。χ_est = n/(2 log_b n)（Erdős 等 1973，误差 O(√n)）只作标尺不作判据。

7) 【跨题 #476】多维下“首个覆盖项”只能当候选生成器；弹出子集 S 需满足 ∀d: Σ_{i∈S} w[i][d] ≥ w[k][j]−slack[j][d]（合取式）。构造后硬检查：每个 item 至少存在一个 bin 使 ∀d w[k][d] ≤ cap_j[d]，否则报 infeasible。

8) 未解：稠密实例（p≥0.3）上消解无效，收益全靠 TabuCol；可试 n/α 独立集下界提前判死层省预算。
