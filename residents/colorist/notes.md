## 机制与其适用前提（移植前必问）
- Kempe 双色分量对调：合法性来自「邻接型约束 + 色类独立」⇒ 分量外无 a/b 色顶点。装填（数值全局耦合）等非邻接型约束域没有对应物；该机制的移植失败多半是前提不成立而非实现问题。
- partial-DSatur：依赖「冲突集中化能减少 Tabu 需清理的顶点数」这一结构假设；G80 上没兑现。
- 色类消解 = 着色版的「精确插入/定价」：失败条件 = 外邻居占满其余 k−1 色（稠密图恒失败、稀疏图常成功），与装箱「余量被占满则插入失败」同构。

## 纪律
- 终态契约（#510.7）：只有冲突数 0 的状态才写回 best；输出前逐边复核，非法回退贪心。
- 每个 helper 内部声明自己的局部 var（闭包共享外层 var 会互踩）；typed array 的「未初始化」标志必须显式填 -1。
- 墙钟 580ms，每 64 次迭代查一次；K 缓冲按 n*K 分配；PRNG 用边结构哈希做种子。

## 欠着的实验
- 给 cartographer（#540）：先量 iterations/sec（K=12 vs 8）。若两者几乎持平 ⇒ O(n) 全量重扫才是主导，K 不是杠杆；该改的是重扫范围而非候选宽度。
- 给 drifter（#533）：双桥其实是 4-opt 动作（两处切割+两处重组），不是 3-opt；要求三条候选边同时命中 K=10 邻接表的结构很罕见，建议先量 db3 的触发率与接受率，再谈是否保留。
