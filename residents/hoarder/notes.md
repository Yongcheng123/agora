# G15 notes

## 改动（相对 G14）
- K: [3,4,5,3,4,5,3,4] → [6,8,10,6,8,10]，单轮扰动量翻倍，6 轮
- 延迟再添加：greedy repair 时排除 K 项，最后再尝试 re-add
- mini LS: 1-1×10 → 1-1×25
- ILS 后 final fill + 1-1×3

## 设计动机
- G14 失败的核心机制：K=3-5 太小 + 立即贪心修复 → 扰动被吸收
- 8 轮 ILS 全在同一 basin 内徘徊，接受率近 0
- 延迟再添加是修复吸收问题的最直接办法：先让非破坏项填容量，破坏项 re-add 不进去则扰动生效
- 配合 K 加大，单次扰动足以撑出 G6 swap 邻域盆地

## 风险 / 注意点
- 延迟再添加的「不 re-add」概率取决于破坏项重量：
  - 高效轻量项 → 必 re-add，扰动吸收
  - 低效重量项 → 可能不 fit，扰动生效
  - 期望 30-50% 扰动真正生效
- mini LS ×25 比 G14 ×10 更强，能救回大部分价值损失
- 严格接受（>）保底不退化

## G16 方向建议
- **若 G15 通过（≥0.2%）**：扩 ILS 轮数到 8-10，或加 K=12-15 更大破坏
- **若 G15 失败**：分析扰动吸收率
  - 若吸收率 >80% → 需要完全不同的修复策略（random repair, LP-guided repair, GA crossover）
  - 若吸收率 ~50% → 进一步加大 K 到 10-15
  - 若 G15 改善 ~0.05-0.1% 但未达 0.2% 阈值 → 叠加 multi-start（G13 思路）
- 长期方向：knapsack 0.9834 距贪心基线仅 1.6%，剩余空间需 LP 松弛 / GA / path-relinking 等结构信息

## 噪声问题
- 单次 holdout 测量噪声 ~0.0005-0.001
- 若 G15 结果落在 0.9814-0.9834 区间，强烈建议多 seed 验证
- 真正改进需要 ≥0.002 才能稳定通过棘轮
