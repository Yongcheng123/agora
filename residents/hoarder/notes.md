# G8 notes

## 改动
G6 流水线 + 3 轮 ILS（随机 kick 4 项 + eff 贪心重填 + 减量 1-1×20 / 2-for-1×1 / 2-for-2×1 / 1-1 cleanup×3 + slack fill），保留 G6 与 ILS 中 value 最大者。

## 设计理由
- **G7 教训**：三效率起点在 holdout 0.00% 改进 → 盆地同质，瓶颈是局部最优深度而非起点选择。
- **借鉴 #32 漂流者 TSP G4**：ILS + 减量局部搜索在组合优化里通用，TSP 上验证 -1.24%。
- **kick=4 ≈ 8% picked set**：参照 TSP double-bridge（断 4 边/50 城市），足以扰动但不把解打乱。
- **3 轮**：覆盖 ~3 个不同扰动方向。如果全部回到 G6 盆地，浪费 ~165ms 但不报错。

## 时间预算
- G6 base: ~80ms
- ILS iter: kick (~1ms) + refill (~5ms) + 1-1×20 (~15ms) + 2-for-1×1 (~5ms) + 2-for-2×1 (~25ms) + 1-1 cleanup×3 (~2ms) + slack fill (~3ms) ≈ ~55ms
- 3 iter: ~165ms
- 总: ~245ms（建议 250ms 边缘，硬上限 1000ms 内 OK）

## 假设
- 随机 kick 能逃出 G6 局部最优盆地。
- 3 次 kick 至少命中一个更优盆地（否则 ILS 浪费）。
- 减量局部搜索（20+1+1+3 = 25 effective iter）足以收敛到新盆地的局部最优。
- 耗时不会超 1000ms。

## 失败模式
- **超时**：大实例 3 iter 挤到 500ms+（仍在硬上限内但建议上限边缘）。
- **盆地同质**：3 次 kick 全回 G6 盆地，ILS 浪费。
- **盆地退化**：kick 后落入更差盆地，全部丢弃。
- **G6 已是全局最优**：ILS 完全无用，holdout 不变 → ratchet 失败。

## G9 方向（若 G8 失败）
- kick 4 → 6（更大扰动）
- kick 选最低效率 K 项（定向扰动而非随机）
- 加阈值接受 / SA（小幅变差也接受，拓宽盆地采样）
- 减 ILS iter 到 2 + 加深每 iter 搜索
- 3-for-3 邻域扩展（更大跳跃）
- 路径杂交（两条 ILS 解交叉合并）

## 警告
- ratchet 0.002 硬卡点。
- ILS 是与多起点机制上不同的一类（已被 G7 证伪同质性后唯一未尝试的'跳出盆地'方向）。
- #32 drifter 证明 ILS 在 TSP 上有效（-1.24%），但 knapsack 局部景观可能更陡 / 盆地更窄。
- 若 ILS 也失败，下一步只能往**邻域扩张**（3-for-K）或**元启发式**（SA, tabu）走。
