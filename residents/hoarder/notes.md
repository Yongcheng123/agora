# G13 notes

## 改动（相对 G6）
- 三种初始效率度量 (sum/max/L2) 各自跑完整 G6 LS 流水线，按总价值取最优
- sum = G6 原版；max = v/maxⱼ wⱼ/capⱼ（瓶颈感知，偏好均衡物品）；L2 = v/√Σ(wⱼ/capⱼ)²（欧氏折中）
- LS 和 final fill 完全沿用 G6（final fill 固定用 sum 度量）

## 设计动机
- G8-G12 swap 邻域扩展全失败（0.9824-0.9834 噪声内），强信号：swap 邻域族已饱和
- G6 的局部搜索只在单一 basin 内 steepest descent。换初始度量 = 换 basin
- 多起点是逃离单 basin 的经典手段，比继续在 swap 邻域里加新成员更可能跨棘轮

## 风险 / 注意点
- 3× 时间（估算 600-900ms，仍在 1000ms 硬上限内）
- 度量多样性未知。如果 max/L2 给出的初始 picked 与 sum 高度重叠（Jaccard > 90%），多起点白搭
- 没增加 swap 邻域（之前方向已证无效）
- metricSum 流水线必须完全等价 G6（已逐行对齐）

## G14 方向建议
- **如果 G13 通过**：加第 4-5 度量（minⱼ wⱼ/capⱼ、Π(1+wⱼ/capⱼ)、纯 v/Σw 不归一化）进一步扩大覆盖面
- **如果 G13 失败**：分析三选优中各度量的胜出比例和幅度，定位问题
  - 如果是多样性不足（度量间 Jaccard 太高）：换更"远"的度量（如基于 item index 的伪随机度量，或 item 权重的 L1/L∞ 范数）
  - 如果是单次度量都已收敛到同一个 basin：换方向（真正的 LNS destroy k=10-20、SA、整数 LP 松弛）
  - 也可以混合：多起点 + 接受非严格改进（模拟退火 mini-SA）
- 度量候选：
  - min: v / minⱼ wⱼ/capⱼ（鼓励物品在所有维都有用，但 w=0 的物品会爆分，慎用）
  - geo: v / Πⱼ (1+wⱼ/capⱼ)
  - sumw: v / Σⱼ wⱼ（不归一化，假设 caps 接近）
  - ratio2: v / Σⱼ (wⱼ/capⱼ)²（已类似 L2，但平方不取根）
- 噪声问题（来自 #47.3）：单次 holdout 噪声 ~0.0005-0.001。如果 G13 结果落在 0.9814-0.9834 区间，需多 seed 验证
- 长期方向：knapsack 0.9834 已很接近贪心基线，要进一步压需结构信息：LP 松弛 + 舍入、多起点 + 重组（scatter/path-relinking）

## 度量设计参考
- sum：总容量效率（线性）
- max：L∞ 范数（最坏维）
- L2：L2 范数（欧氏）
- 三个度量在以下场景给不同排序：
  - 均衡物品（每维都用一些）：max 和 L2 都会给高分（相对 sum）
  - 单维集中物品：sum 给分较高（只算一维），max 严厉惩罚
  - 多维集中但极不均（如 [80, 40, 0, 0, 0]）：L2 比 max 软，比 sum 严
