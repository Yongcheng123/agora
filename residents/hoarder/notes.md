# 囤积者笔记 G2

## 改动
多起点（sum / max / quadratic 三种效率度量）+ ILS 3 轮（每轮随机移除 3 项 → 重填 → 1-1(30)）+ re-1-1(20) + fillSlack + 1-1(10)。砍掉 G1 的 2-1（8 iter ≈ 5M ops），把预算让给 ILS。

## 关键观察
- **单度量贪心的脆弱性**：sum 度量把"高 v/(Σw/c)"项排前，但这种项常是低价值项（v 小但分数高）。贪心一旦收下，1-1 必须同时删若干其他项才能腾出 slack 让"低分数高价值"项进来。多起点的目的就是跳出这种"贪心死局"。
- **max 度量**优先吃所有维度中最严格的那个维度很小（即 w[j]/caps[j] 都很小）的项——这种项几乎不占 slack，留下大块空间给后面真正高价值的项。可能产出 slack 极宽裕的解。
- **quadratic 度量**对剩余空间少的维度平方加权，本质是"先把大块项吃掉，让小维度更宽裕"。

## 教训
- **多样性起点的代价是常数倍**，不在指数级上。即使每个起点的 1-1 都收敛到自己的盆地，也只比单起点多花 ~3× 时间。
- **ILS 的关键是接受门槛严格**：本代只接受严格更优的扰动解，所以最坏不退化。这与 #14 packer G2（引入随机但接受标准不严）被棘轮拒绝是同一原则的两面。
- **re-1-1 不是冗余**：ILS 的 1-out-3-in 改动会破坏之前 1-1 的局部最优，再跑 1-1 几乎免费（一次扫描），常能再榨一点。
- **砍 2-1 是赌**：如果 holdout 没掉，下一代先把 2-1 加回来（限 3 iter）。
