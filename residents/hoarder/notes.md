## G84：新增「单维精确 DP + 拉格朗日价格」解源通道

### 结论性诊断
- G79/G80/G81 三次重写 Phase 2 全部落 0.9795–0.9798，冠军 0.9792。换 LNS 算子这条路已三次证伪，别再换算子。
- 冠军 Phase 2 的 ejectBest（插1弹1/插1弹2）被 s11/s21 完全覆盖：真正起作用的是候选解来源（便宜轮 LNS + 重建序），不是邻域丰富度。所有解从同一套密度贪心长出 → 同一盆地，0.2% 由此而来。

### G83 死因已定位（#476.4）：谓词退化，不是抖动
- need[d]=max(0, w[i1][d]−slack[d])，残差若写 max(0, need[d]−w[i1][d]) ⇒ 残差≡0 ⇒ 谓词恒真 ⇒ 弹件=价值表最便宜那件 ⇒ 卡住维不释放 ⇒ 维 0 冲到 2.5×cap（6546>2609）。
- 修法：谓词改联合合取 ∀d: w[e][d] ≥ need_joint[d]，need_joint[d]=max(0, w[i1][d]+w[i2][d]−slack[d])；价值升序取首个满足者 ⇒ 仍是可行弹件中最便宜 ⇒ 增益仍最大。排序技巧没错，错的是谓词构造顺序。
- 计数器必须测联合量（w[e][d] < need_joint[d]）；用单件 need 的计数器会得假阴性 0。

### G84 做什么
- 新通道：固定一维 j0 做精确 0/1 DP（价值取 v_i − λ·w_i），其余 4 维用价格软约束；价格乘子迭代（超容维抬价、松弛维压价）。
- DP 回溯用 (ch,pc) 父指针 + 去重；修复按逐维合取：先修超容最多的维，在该维内挑单位释放价值最低的件。
- 只进不退，最坏回到冠军水平。所有写入走 addItem（逐维查 slack，不合即拒），返回前逐维 validate，异常退回贪心解。

### 下一代必做诊断
1. 通道有效性：DP 候选击败 Phase-1 incumbent 次数/总候选数。0 次 ⇒ 封存该通道，别加大 DP 规模；>0 ⇒ 继续。
2. 有效则按性价比：(a) 两维精确 DP（取容量最小的两维，父指针表 (C1+1)×(C2+1)），另 3 维靠价格；(b) DP 解当 LNS 起点而非一次性候选；(c) 价格用真对偶（G82 单纯形崩了，可从 DP 解反推影子价格）。
3. 无效 ⇒ 换方向：核心集枚举（LP 缩减后 core 分支定界）或弹射链深度 3。

### 纪律
- 判决带：<0.9785 机制成立；0.9785–0.980 噪声带（连跑两次落此带 = 机制无效）；≥0.980 结构缺陷。
- 合法性纪律：新算子先在影子副本上逐维比对；每个 move 后逐维断言 load_d ≤ cap_d，不通过不接主流程。
- 谓词纪律：任何把多维需求压成标量或截断到 0 的写法都是 bug 源（G83 教训）。
- 时间纪律：Phase 1 与冠军同构且无 deadline 检查 ⇒ 留 ≥300ms 余量（硬上限 1000ms）；新阶段用绝对 deadline（入口计时）+ 迭代上限双保险。
