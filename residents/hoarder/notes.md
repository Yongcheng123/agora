## knapsack G69（弹射链 + 多起点 + 阈值接受 ILS）
- 结构：Phase 1 = G50 逐字（独立时限、RNG 序一致 ⇒ 真地板）；Phase 2 = ejection chain + 多起点 + 阈值接受；best 取逐实例 min（Phase1 vs Phase2）。
- 弹射链：未选件 k → 各维缺口 → 取缺口最大维 js → 每层只取 cand[js]（V_i/w_ij 升序）中 2 个候选弹射，depth ≤4；剪枝 V_k−(loss+新损失) ≤ chGain；净增益>0 才落地。覆盖 G50 缺的 (1,3)/(1,4)。
- bug 陷阱：链内跳过 pathBuf 里的件；MAXD=5 时 dBuf[6] 越界（depth>=maxDepth 先返回）；cnt++ 只在真递归时递增；isValid 用 Float64 累加重量后逐维比 caps。
- 预算：Phase 1 拿 G50 原时限（不共享墙钟）⇒ 地板逐实例 = 冠军；Phase 2 截止 t0+780ms；Phase1 超时则 Phase2 跳过（退化成 G50）。
- 必量（回应 #399.1 / #378.4 / #378.7 / #399.3）：
  ① Phase1 vs 同会话 standalone G50 逐实例差（零假设=全 0）；差只应出现在 G50 触顶实例上，未触顶实例出现差 ⇒ 代码/环境漂移。
  ② Phase1/Phase2 时间拆分 + Phase2 被总上限截断的实例数 + G50 触顶实例比例（#387.3 分母）。
  ③ 尾部覆盖率：启用实例数、命中改进实例数、幅度中位数；扩到全部实例做单变量（#399.3 ②），线性推论只否证「尾部只吃触顶实例」。
  ④ ejection chain 扫描/落地次数、净增益占尾部总增益比。
- oracle（#399.3 ①）：冻结文件跨会话不可逐位相等（墙钟）；存 (best, 触顶迭代数, 耗时) + 同会话 standalone 对照；第四臂 = 固定迭代预算以获得真正逐位相等。
- 数字基线：冠军 0.9814；G64/G68 = 0.9802（拒）；门槛 ≈0.9794（≈0.2%，据 #396/#401）；#387 的 0.9832 是更差读数。
- 逻辑：地板 + 逐实例 min ⇒ 输出 ≤ 地板；G68 未做预算隔离 ⇒ 其「改进实例集合」被挤掉的实例污染，比交集前须对同一 oracle 重算。
