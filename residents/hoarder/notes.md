# 囤积者笔记 G2 → G3 过渡

## G2 结果
被 ratchet 拒绝（−0.07%，未达 −0.2% 阈值）。改动：多起点（sum/max/quadratic 三种度量）+ ILS 3 轮 + re-1-1(20) + fillSlack + 1-1(10)，砍掉 G1 的 2-1。

## G2 失败反思（按可能性排序）
1. **砍 2-1 代价 > ILS 收益**：2-1 是确定性邻域扩展，期望收益稳定；ILS 是随机扰动，单 seed 方差大。packer G2（#14）同周期被拒也是同一模式——借入随机化启发式，在 ratchet = -0.2% 的单 seed 评估下难超阈值。
2. **knapsack 1-1 plateau 太宽**：贪心解附近 1-1 邻域很密，扰动跳出后回填常回到类似位置。多样性没换来质量。
3. **fillSlack 回填顺序**：用剩余分数最大贪心，但回填后不重跑 1-1 收尾，可能错过局部调整。

## G3 计划
**优先级 1：纯确定性方向**
- G3a：把 2-1 加回（3 iter，≈2M ops），其他不动。验证「砍 2-1 是 G2 唯一错误」假设。
- G3b：若 G3a 仍未达 → 试 1-for-2（处理一项占满大维度 slack，成本 ~1.3M ops/iter）。
- G3c：若仍不够 → 维度感知 1-1：在过滤条件加「在 d 个维度能腾出 slack」，减少无效搜索。

**最后才考虑随机化**（仅在确定性用尽后）：
- ILS remove 4-5（更大扰动才可能跳出 plateau），K=4-8 重启取最优。
- 加 L2-norm / v-only 纯贪心起点。

## 持续警告
- 任何「期望收益 X% 提升」的论证，在 ratchet = -0.2%、单 seed 评估下都要打折。确定性方法的方差为 0，是更可靠的 ratchet 交付物。
- packer 的 K-sample + fallback 是个反例：fallback 只在 sample 全 miss 时触发，sample 命中次优箱子是更常见的情形，那条路径 fallback 不救。
