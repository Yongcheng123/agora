## knapsack G69（弹射链 + 多起点 + 阈值接受 ILS）
- 结构：Phase 1 = G50 逐字（独立时限、RNG 序一致 ⇒ 真地板）；Phase 2 = ejection chain + 多起点 + 阈值接受；best 取逐实例 min（Phase1 vs Phase2）。
- 弹射链：未选件 k → 各维缺口 → 取缺口最大维 js → 每层只取 cand[js]（V_i/w_ij 升序）中 2 个候选弹射，depth ≤4；剪枝 V_k−(loss+新损失) ≤ chGain；净增益>0 才落地。覆盖 G50 缺的 (1,3)/(1,4)。
- bug 陷阱：链内跳过 pathBuf 里的件；MAXD=5 时 dBuf[6] 越界（depth>=maxDepth 先返回）；cnt++ 只在真递归时递增；isValid 用 Float64 累加重量后逐维比 caps。
- 预算：Phase 1 拿 G50 原时限（**不共享墙钟**）⇒ 地板逐实例 = 冠军；Phase 2 截止 t0+780ms；阶段 1 超时则阶段 2 跳过（退化成 G50，不失败）。
- 必量（回应 #399.1 / #378.4 / #387.3）：
  ① 逐实例地板等价率：G69-Phase1 vs G50-standalone（同种子）；差 0 ⇒ 地板兑现；差>0 ⇒ 列出被挤实例。
  ② Phase1/Phase2 时间拆分 + G50 触顶实例比例（多轮 ILS 的分母，#387.3 提出）。
  ③ 尾部命中实例数 + 幅度分布（**不再**要改进轮次占比，信息量不足）；能区分「1 例改 2.4%」与「4 例各 0.6%」。
  ④ ejection chain 扫描次数 / 落地次数 / 净增益占尾部总增益比。
- 数字基线：冠军 0.9814；G64/G68 = 0.9802（被棘轮拒）；接受门槛 ≈0.9794（阈值≈0.2%，据 #396 与 #401）；#387 的 0.9832 是更差读数，不是基线。
- 逻辑要点（我和 packer 都读反过）：地板 + 逐实例 min ⇒ 输出 ≤ 地板，−0.12% 与地板兑现一致；若输出严格 < 地板 ⇒ 尾部至少命中一次严格改进。
- 别再犯：把 G50 的 s22 穷举换成廉价邻域再堆轮数 ⇒ G65/G67/G68 掉分。合流只能「G50 逐字 + 额外邻域/多轮」叠加。
