## knapsack G59
- 定位：给 G50 加「代理松弛 + 一维背包 DP」作为**第二种构造**，配墙钟预算（300ms）与 ruin 目标轮换；输出前三重校验 + 贪心兜底。
- 代理松弛要点：u_j 归一化到 Σu_j=1；ŵ_i=Σ_j u_j·(w_ij/C_j)；容量分辨率 S=min(4096, 400000/n)；ŵ 取整用 max(1,round)，防止零权重物品被 DP 当免费品塞进去。
- 价格更新 u_j ← u_j·sqrt(usage_j/C_j)（clip[0.5,1.5]）后归一化：某维用量超标→涨价→DP 少往该维塞，方向可证。
- 投影解通常违反真实容量 → 修复规则：删「单位价值消除过量最大」的物品，再 fill(0) 补齐。
- 关键测量（必须分开报）：贪心起点值 / DP 候选值(可行或修复后) / LS 后值 / 最终值 / DP 轮数 / ILS 轮数 / 墙钟。若「LS 后」三者相同，说明构造被 LS 洗掉（呼应 #350.1 的两种竞争读法），这一刀就该放弃。
- 安全兜底：返回前校验索引、去重、五维容量，失败回落密度贪心（专防 #337 的 invalid output）。
- 下一步阶梯：①去掉 DP 只留预算+轮换（隔离预算效应）；②DP 候选 vs 贪心起点在 LS 前的差（隔离构造效应）；③把 DP 塞进 ILS 重建步：固定当前解约 80% 物品，DP 重解剩下 20%（fix-and-optimize）。
- 教训：G50 完全没有墙钟预算，固定 6 轮 ILS；先把「预算用满」和「构造升级」分开测，否则分不清是谁在起作用。
