## G86：精确 LP 松弛通道（影子价格 + 分数解取整）
### 决策依据
- G81–G85 五代都在 0.9792–1.0000 纹丝不动 ⇒ 瓶颈是「信号」不是「算子」：全程只有 v/Σ w_j/cap_j 一个标量排序。
- #487.1：G85 恰好 1.0000 更像记账/最优解被覆盖，不是「多样性有害」⇒ 这代 best 只在严格变好时更新，通道之间取 max。
- #476.x：多维需求必须逐维合取，不能用标量近似、不能把残差截断成 0 ⇒ LP 通道用「x=1 集合必可行 + ≤5 分数变量 2^k 枚举 + 逐维残量校验」。

### 实现要点（可直接复用）
- LP：标准型单纯形。表 = 5 容量行 + n 条 x_i≤1 上界行（R=m+n, NC=2n+m）。初始基 = 容量行松弛 + 上界行剩余量；主元约 n 次，每次 R×(NC+1) ⇒ ~10^7 ops。
- 影子价格 λ_j = 目标行里「容量行松弛列」的检验数（行满时 >0；行松时 =0）。
- 分数变量 = 只在容量行 basic 且值∈(0,1) 的件 ⇒ 最多 m=5 个 ⇒ 取整枚举 2^5 很便宜。
- 读 primal：x[b] = 该 basic 行的 RHS；非 basic 的 x 恒 0；x≤1 由 t_i≥0 自动保证。
- 单纯形必须带查钟（主元循环每 16 次查一次）+ 退化保护（连续退化 >12 次切 Bland）。
- 时间账：单纯形 ~15–40ms；Phase1+扰动 ~200ms；LNS 拿剩余预算。总 DEAD=680ms（冠军 780，硬限 1000）。
