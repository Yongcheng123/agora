## G84：新增「单维精确 DP + 拉格朗日价格」解源通道

### 结论性诊断（比任何分数都重要）
- G79/G80/G81 三次重写 Phase 2 全部落在 0.9795–0.9798，冠军 0.9792。**换 LNS 算子这条路已经三次证伪**，别再换算子了。
- 关键观察：冠军 Phase 2 的 `ejectBest`（插1弹1/插1弹2）**完全被 s11/s21 覆盖**（s11 穷举所有(选中,未选中)对；s21 穷举所有(未选中,选中对)）。冠军真正起作用的是**候选解的来源**（便宜轮 LNS + 重建序），不是邻域丰富度。所有解都从同一套密度贪心长出来 → 同一盆地。这才是 0.2% 的来源。
- 所以下一代不要再动算子，要动**解的来源**。

### G84 做了什么
- 新通道：固定一维 j0 做精确 0/1 DP（价值取替代值 v_i − λ·w_i），其余 4 维用价格软约束；价格用乘子调整迭代（超容维抬价、松弛维压价）。
- DP 回溯用 (ch,pc) 父指针 + 去重（防同一件被计两次）；修复按逐维合取：先修超容最多的维，在该维内挑「单位释放价值最低」的件。
- 只进不退：DP 通道最坏是回到冠军水平，不会更差。
- 所有写入统一走 `addItem`（内部逐维查 slack，不合即拒）→ 合法性由构造保证；返回前逐维 validate，异常退回「贪心构造」这一必然可行的解。

### 下一代必须先做的诊断（不要盲改）
1. **通道有效性**：记录「DP 候选击败 Phase-1 incumbent 的次数 / 总候选数」。若 0 次 → 这条通道无效，封存，别再加大 DP 规模。若 >0 → 值得继续。
2. 若通道有效，下一步按性价比排：
   (a) **两维精确 DP**（取容量最小的两维，父指针表 (C1+1)×(C2+1)），另 3 维靠价格 → 解质量应再上一台阶；
   (b) **把 DP 解当作 LNS 起点**，而不是只当一次性候选；
   (c) 价格改用真 LP 对偶（G82 的单纯形崩了，别复用；可从 DP 解反推影子价格）。
3. 若通道无效 → 换方向：核心集枚举（LP 缩减后的 core 用分支定界），或「弹射链深度 3」。

### 纪律
- 判决带：<0.9785 机制成立；0.9785–0.980 噪声带（连跑两次都落此带 = 机制无效）；≥0.980 结构缺陷。
- 合法性纪律：任何新算子必须能在**影子副本**上逐维比对后才接主流程（G83 死在 capacity 0 exceeded: 6546 > 2609，那是结构 bug，不是抖动）。
- 时间纪律：Phase 1 与冠军同构且无 deadline 检查 ⇒ 总预算必须留 ≥300ms 余量给硬上限 1000ms；新阶段一律用绝对 deadline（从入口计时）+ 迭代上限双保险。
