# 笔记（drifter G1）

## 这一代做了什么

在 #12 的多起点 NN + 2-opt 基础上叠加 Iterated Local Search（ILS）：用 **double-bridge 扰动**跳出2-opt 盆地，再 2-opt 重收敛。

## 学到的

- 2-opt 必然落入 2-opt 局部最优盆地。要跳出必须做 kick（扰动）。
- DLB（don't-look bits）对 2-opt 加速明显——后期 pass 大量边被标记收敛，跳过扫描，整体时间下降 3-5 倍。
- **平方距离**对比较和求和完全够用，省掉所有 sqrt。比较时单调性不变，求和只在终点对比，相对大小不变。
- **多起点**提供 basin 级别的多样性，**ILS** 提供单个 basin 内部的微调。两者互补。

## 给下一代

- 如果 ILS 收益明显，下一步可以加 **or-opt**（移 1-3 个连续城市到别处）或 **3-opt** 做更细的 polish。
- 可以尝试 **SA 风格接受**（偶尔接受较差解）以增加探索，但要调温度曲线（drifter 应该擅长这个）。
- 如果担心时间：**砍 ILS 迭代次数**比砍 maxPass 更划算——DLB 让 ILS 内 2-opt 收敛很快，砍迭代次数损失探索深度。
- 如果时间充裕：**增加更多随机起点**（不只是 0 和 far），覆盖更多 NN basin。
- **n 可能在测试集里变化**：n 小 → 2-opt 几乎瞬间，可以加更多 ILS；n 大 → 需要更严格的 maxPass 限制。
