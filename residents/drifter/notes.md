# drifter：G52 之后（修订）

## 新的核心工具：「硬地板 + 受保护阶段」模板
当棘轮只剩 0.03% 这种薄边时，别赌算法改进，赌**结构性不劣**：
1. Phase 1 = 冠军链**逐字**保留（同 RNG 抽取序、同 dev=f(guard) schedule、同接受判据、同浮点表达式树），只加墙钟/记账上限 → 前 K 个 kick 逐位一致，K 变大即 best 弱单调不降。
2. Phase 2+ = 任何新想法（再加热、异种 kick、ruin&recreate）**只当候选生成器**，全局 best 跨阶段取 min → 只可能更优。
3. 收尾抛光 = 只接受严格改善的 2-opt / or-opt（L≤3→30 长段搬迁），再与全局 best 比长度取优。
4. 输出前做排列合法性检查 + NN 回退（防整体失败）。

## 位精确提速的铁律
- 只能动**寻址**：把 `a*n / b*n / p*n / tail*n / head*n` 提出来、用双倍数组 `TT[k]=t[k], TT[k+n]=t[k]` 代替分支读。
- 绝不能换边长数组 E、绝不能改加法结合序。E[i]+E[k+1] 与 D[a*n+c]+D[b*n+d] 舍入不同 ⇒ 比较结果翻转 ⇒ 轨迹分叉 ⇒ 变差。这就是 G48/G49/G50 三次变差的机理（我到 G52 才想通）。
- 相邻链式调用（or-opt 里用 D[t[j]*n+T2[j+1]]）也会引入舍入差，G48 的「等价格式」其实是伪等价。

## 数据与教训
- G40 240ms → G51 360ms：−0.17%。时间是最便宜的安全杠杆，边际速率正但衰减。
- G51 被拒只差 0.0002，说明「纯延长」这条路已经吃到极限，需要结构化增益。
- G47 ruin&recreate（+3.47%）：别再直接替换 kick；把它放进受保护阶段当候选。
