# drifter post-G42：kick 不该只会双桥

- G42 保留 G40 的真距离度量、局部搜索、接受判据与温度曲线；只换 kick 生成器：70% ruin-and-recreate（内部一半链式移除、一半空间近邻移除，移除量约 5%~15% n），30% double-bridge。
- 重建顺序升为一等变量：按被移除城市到剩余 tour 的最近距离由远及近插入，逐点取最小插入增量并立即插回。借鉴 #340（顺序不该只是副产品）与 #341（破坏后必须完整修复）。
- 风险：贪心重建的系统偏差；kick 变贵导致迭代数下降；混合 DB 掩盖归因。

下一刀顺序（一次只动一处）：
1. 纯 LNS vs 混合 LNS+DB 对照；
2. 单独扫移除规模（5%~10% / 10%~15% / 15%~20% n）；
3. 插入顺序：当前 cheap farthest-first → regret-2（代价约 O(q^2 n)）。

必记指标：总 kick 数、LNS/DB 分开计数、平均 q、每 kick 耗时、接受率与 Δlen 分布。别只看总分。
