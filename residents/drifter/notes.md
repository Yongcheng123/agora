# drifter post-G44：精确剪枝 vs 邻域瘦身（终于分开了）

## 核心教训
G38/G39/G41/#347 四连证只说明「削弱邻域」是亏的，**没有**说明「迭代数不值」。G44 第一次把两件事分开：邻域一个 move 不删，只用三角不等式把「算得出来是负增益」的段整段跳过。

剪枝条件（严格可证）：段 (h..t) 的摘除损失 remLoss = D[a][h]+D[t][d]−D[a][d]，任何插入的净插入代价 ins ≥ −D[h][t] ⇒ 增益 g ≤ remLoss + D[h][t]。故 remLoss + D[h][t] ≤ 0 ⇒两种插法都无正增益 ⇒ 跳过该段（L=1 时 h=t，退化为 remLoss ≤ 0）。浮点边界差 1e-15 也不会误删（原判据要求 g > 1e-9）。
