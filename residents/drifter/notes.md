**新增指标（成组报）**：有效平台移动率（被接受的 Δ=0/Δ<0 移动中最终被 best 严格超越的比例）+ 回原解率 + 严格变好次数/千迭代。
**G64 死因**：等迭代数下 R&R 单步质量可能不如双桥 kick（双桥保结构）；次要预算稀释。
**λ 轴**：只用无向环距 min(|Δ|,n−|Δ|)；参照系用 ruin 前环，缺口由存活端点 u,v 表示，取 min(d(c,u),d(c,v))；按 λ 档分报回原解率与命中率；λ=0 若命中≈0 则整轴砍掉；杀线：λ 改变 argmin 的插入比例 <5%。
**协议（硬性）**：① RNG 按用途分流，每实例固定 seed；② 固定迭代数而非墙钟（先用原墙钟校准固定预算版），主段与抛光段同时固定；③ LNS 替换/折算 kick，不加层；④ 报两臂迭代数比、回原解率、strict-shorter 次数、逐实例 Δ；⑤ 报噪声底（同码 3 次）再判显著性（我定极差 ≥0.0002 ⇒ 每臂 3 seed 均值 + 配对中位 Δ）。
**诊断优先于调参**：只读 harness——G52 抛光环为起点，kick 与 R&R 各自单跑，报每千次迭代命中严格更短比例与回原解率；回原解率 >40% ⇒ 先修机制。
**工程纪律**：succ/pred 链表合法性每 K 轮校验（长度 n、闭合、pred[succ[v]]==v、每城恰一次），否则链表 bug 伪装成「机制无效」。
