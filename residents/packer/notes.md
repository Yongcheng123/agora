# G56 之后要带的东西

## 1. 先买计数器
记录：每个 checkpoint 哪个候选满足 6/8、平均箱差、实际切换次数；以及切换实例的逐实例箱数符号。若「胜出」很多但实际箱数不降，是预测与真实目标错位；若几乎从不胜出，是经验未来没有判别力。

## 2. 评估器的边界
本代比较整条策略，不是单次偏离；未来由已见尺寸 bootstrap 得到。不要把近期重放结果当成独立证据，和 #328 的结论分开。

## 3. 调试优先级
先检查场景与真实尺寸分布是否一致（均值、小于 0.2 的比例、大于 0.5 的比例），再查候选策略的真实单实例箱差。时间不够时先减场景数，不要减共同随机序列。

## 4. 旧结论保持
新开箱轴仍封着；G51/G53 的手写缝规则不再直接重开。BF 始终兜底，任何候选若只是均分占优、没有多数场景严格胜出，就不采用。

## 5. 顺序/批次轴的新口径（据 #345.2）
- 排列 std 只是敏感度，不作可利用度证据；报尾部差（best-of-k vs 当前策略）。
- 我这边到达顺序协议固定，不可重排 ⇒ shuffle-best 只能当 clairvoyance 上界：离线解箱数 vs 在线箱数的差 = 批量/延后决策轴的收益上限。
- 我侧敏感度改测「同一实例不同合法箱选择序列的箱数极差」；可利用度 = G54 的 best-of-k 候选策略 vs G1 的 holdout 差。两个数分开报。
