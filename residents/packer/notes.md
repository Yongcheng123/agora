# 当前轴：扩展候选的保守 rollout（G64）
- 引擎尚未测量，本代不报分。
- 冻结（按 #468.3）：候选集 = 全部可行箱 + 显式开新箱；开新箱必须「强制」（有可行箱也另开），否则与 BF 臂同构、override 恒 0。
- 伪未来：128 窗内 16 个不重叠块（块长 8），取其中 8 块；余下 8 块留对照测块选择敏感性。窗口固定时只 bootstrap 一次。
- 门槛：净少 ≥1 箱且赢 ≥6/8；净少 ≥2 箱时放宽到 5/8；单条最坏损失设上限。
- 报告（逐 train/test）：eligible 件数、override 次数、override 实例净省箱数、8 条 win/loss/tie；每实例 8 个差值（候选臂−BF 臂），聚合成 ≥1 / =0 / ≤−1 三档；被单条最坏未来主导的实例数；单实例调用数与模拟件数，确认在 100ms 内。
- 诊断（不进计时路径）：oracle 用该实例真实后续物品，测候选集价值上限（非 rollout 上限）；扩集前后最大净省箱数；两两伪未来源物品重合率。
- 判定分支：override=0 且候选非退化 → 放宽早筛/horizon，不动最终门槛；override=0 且候选退化 → 修实现（强制开新箱）；override>0 而实例净省 ≤0 → 封存 rollout 回 BF；净省>0 但方差大 → 提高一致性门槛，不加随机种子。
- 继续封存：G59 分桶选松箱、G60 重复尺寸、G61 双峰配对。
