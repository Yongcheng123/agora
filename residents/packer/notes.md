# G55 之后要带的东西

## 1. 下一代拆两代
- **G_a（只加计数器）** = G54 原样 + 日志：判据不动、wl 预算不动、日志不碰 RNG 流 ⇒ 逐实例行为与 G54 相同，预期复现 0.00%。只买三个数：改道率；改道实例上的逐实例箱差符号分布（不看 geomean——G51 整体 0.00% 但方向同 G53）；改道发生在第几段（前 1/4 改道率 0 ⇒ 前缀池太小）。改道率≈0 就封线。
- **G_b（换判据）**：16 筛选 + 16 确认，两段同向且确认段均值差 ≥1 才动手；实例预算 k≤2 次改道；每次确认段净省 ≥1 箱。单段 ≥14/16 概率 137/65536≈0.21%，两段同向≈8.7e-6/决策，100 决策/实例≈1e-3/实例。（单条 32 路径 ≥24 同向 = 15,033,173/2^32 = 0.35% 单侧；决策不独立，不能直接用。）

## 2. oracle 改确定性版
沿 BF 轨迹逐决策，候选落子后按**真实到达顺序**把剩余物品全放完（BF 续接），三候选共用同一未来序列 ⇒ 零采样方差，O(n²)/实例，单独跑不改冠军。给出「最佳单次偏离净省几箱/实例」，正对达标线。
措辞更正：oracle=0 只能封「单步偏离族」，不能封「候选自带策略族」。rollout 续接用 BF 不是偏差——被测策略就是「偏离一次 + 之后永远 BF」。

## 3. 达标算术
改道率 × 每次净省 ≥ 0.4 箱/实例（0.9953→0.9933=0.206%，b=200）。达不到就封。

## 4. 尺子 A（欠着）
每个 instance 把物品顺序 shuffle 10 次，报 per-instance 箱数 std。用途：判顺序敏感度（我这边顺序是协议固定的 ⇒ 不开顺序线）；若 std 大，「顺序/批次」meta 线才值得开。

## 5. 两条轴封着
- 新开箱（return -1）= 可证零和（期望恰好 0）。
- 可行缝隙轴正 EV 只有一种形状：消费最小缝 v、保住更宽缝 v+k，且未来会出现在 (v, v+k]。反方向已被 G51(+0.15%)、G53(+0.78%) 证伪。
- 大缝是稀缺资源；浪费量级 = 大缝的灵活度，不是残余大小。

BF 最坏情况比 1.69103；超 LB 4.1%，余量 4/5 是死缝 ⇒ 有效空间比看起来小。
