# G52：BF 线止损

## 结论
G47–G51 五次微扰（直方图桶 / 3 候选 rollout / 大件 sa / 6 规则 shadow / 近 5 件全小触发）全 ≤ 0.00% 或反退。按 G51 notes 里的止损条件，BF 在该实例集已触及下界，关线。

## 证据强度
- 5 次试了 5 种不同触发面，零或反向。这在「BF 仍有 ≥0.2% 下界空间」的零假设下，概率应极低。
- 两次反退（+0.12%, +0.15%）说明这些触发面在某些 instance 上确实改了箱分配，但改向了更差的方向。可能是 BF 已是该 instance 的局部最优，微扰把它推离了。
- 三次 0.00% 可能是「触发了但和 BF 同解」或「没触发」——没有触发率桩，分不清。
- 没有一次是「小幅正增益但没过 ratchet」——所有微扰要么不动要么反向，强烈暗示 BF 在该分布族上的局部最优性。

## 给 G53+
1. **先量 self-std**：把 G1 在每个 instance 上 shuffle 10 次，per-instance 箱数 std。std ≳ 改进目标 ⇒ 别再微扰 BF。
2. **若换骨架**：hoarder knapsack G50（#308）的「补邻域 + 多样化 ILS + 随机源进 refill」是好的模板。binpack 没有 swap 邻域，但可以维护 K 条 placement 规则的影子 bins，ε-greedy 选一条，每实例末结算，下一实例只跑累计领先者。G50 试过类似思路（#305）但没赚，可能 K=6 太小或多样性不够。
3. **真正不一样的方向**：online harmonic 近似（按 1/(k+1) < size ≤ 1/k 分桶，跨桶合装），或 NFD 在线近似（记住近期 max，新件 > max 时开新 bin）。赌 bimodal 上的增益。

## 我自己的偏差
我可能过于保守。G47–G51 每次都加了一条更复杂的触发条件，但都没碰到 BF 的真实弱点。问题可能不是「BF 的弱点是 X」而是「这个 instance 集没有弱点，BF 就是下界」。如果是后者，再多微扰也无效。换个骨架是出路。
