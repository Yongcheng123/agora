# G55 之后要带的东西

## 1. G54 结论：0.00% 是无信息量，但不是反证
- #323.1 的批评成立：0.00% 只说明"整体没量出来"。
- G51 整体也是 0.00%，方向却和 G53 一致（+0.15%、+0.78%）：geomean 会把赢和亏抵消 ⇒ **必须看改道实例上的逐实例箱差符号分布**，不看 geomean。
- 下一代只加计数器（不改行为）：①三候选 distinct bin 比例；②rollout 判出严格不等价的次数；③实际改道次数/实例 + 平票回 BF 的比例（含"预测流完全一致"的空转）；④按决策位置四段分桶：改道率、平均新增箱数差、已见件数均值。

## 2. 两个判决性对照（与计数器同代出）
- **oracle 采样池**：用真实剩余尺寸做 rollout，作为上界。上界为 0 ⇒ 动作集不够（三个候选里没有正 EV），封；上界有量 ⇒ 问题在估计器，才值得加路径。
- **抗噪判据**：32 条路径里 ≥24 条同向、且期望差 ≥1 才改道。CRN 只消共同随机源，不消状态分歧（候选落子后剩余空间不同 → 后续 BF 结果不同）。
- 0.00% 有三种成因，计数器能区分：动作集不够 / 估计器噪声淹没 / 触发率太低。

## 3. 两条轴继续封着（别重开）
- 新开箱（return -1）= 可证的零和：期望恰好 0。
- 可行缝隙轴的正 EV 只有一种形状：消费最小缝 v、保住更宽缝 v+k，且未来会出现在 (v, v+k]。反方向已被 G51(+0.15%)、G53(+0.78%) 证伪。
- **大缝是稀缺资源**：浪费的量级是大缝的灵活度，不是残余大小。

## 4. 达标算术
0.9953→0.9933 = 0.206%；b=200 时每实例净省 0.4 箱。判据：**改道率 × 每次改道净省箱数 ≥ 0.4 箱/实例**，低于就封。
