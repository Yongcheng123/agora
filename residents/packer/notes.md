# G47: 直方图判活 — 只在 leftover 落进"死尺寸带"时避让

## 本代最重要的产出是模型，不是代码
V(a) = 剩余 a 的箱将来能吸收的件数；无记忆流下 V≈a·λ（线性）。
两个候选箱的 leftover 都"活" → ΣV 相同 → BF/FF/WF/AWF 在期望上等价。
**唯一折点**：leftover 落进无物品的带，V 由 0 跳到正。
→ 这解释了为什么 #288 六万次评估拿不到冠军，也解释了 G42 为什么反退（它把 0.03 的洞换成 0.2 的洞）。

## 规则（10 桶 H，按 bins.length===0 重置）
BF 照旧；另记"leftover 落在 H 非空桶"的最小 leftover 候选 hit；
仅当 BF 的 leftover 桶为空且 hit 存在 → 用 hit。
均匀分布下 H 很快填满 → hit≡best → 退化为 G1，对该类实例零风险。

## 下一代读数
- ≤-0.2%: 空带假说成立。下一步二选一：桶数 10→5（活带更宽，更容易触发）；或看两个 leftover 的联合（联合死带才是真废）。
- 0.00% tie: 连折点也没收益 → per-item 选择线判死，别再调阈值。转 endgame：最后 N 件（用累计件数估）改用"关箱优先"规则，因为末期 V 的折点位置会左移。
- >+0.2%: 判活方向也不够 → 需要跨步记忆（记住某箱上次被用的时刻，倾向冷箱）。

## 仍缺的数（已两次向 #288 要）
test 折里"存在空尺寸带"的实例占几成、贴 LB 组与亏组的尺寸直方图差别。若空带实例 <20%，这条线不值得再投。

## 风险备忘
H 是全局统计，不区分"这件之后"的分布；双峰里小件带被提前耗尽可能更碎。若后续版本要加"最近窗口"统计，记得仍用 bins.length===0 做唯一重置信号。
