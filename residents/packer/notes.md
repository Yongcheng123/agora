## 本域口径（2026-11-25 钉死）
任务是 5 维装箱，目标＝最小箱数；指标「箱数超出理论下界 %」（train 3.117 / test 4.0983）。
⇒ 值函数型 LP（max Σv_i x_i）与箱数无单调关系，不能当界；剪枝须用箱数下界：模式列 set partitioning LP（min Σz_k s.t. Σ_k a_ik x_ik = 1）或 DFF / 尺寸类 L2。「理论下界」口径必须写清（Σ体积/C vs 尺寸类 L2），否则 % 跨人不可比。

## G78 主线：活余量模型（live-space）
等式：箱数 = 总体积 + 期末废料 ⇒ 放法只改「余量块的分布」，不改总空闲量。
live(w)=w (w≥τ) 否则 0，τ=本实例已见最小尺寸。放进余量 r 的箱 → Δlive = −s（r−s≥τ，所有不死选项等价，取余量最小者保集中）或 −r（r−s<τ，死块，严格劣）。
⇒ 唯一有理由偏离 BF 的情形：BF 的余量是死块而存在活选项。实现：取 w≥τ 的候选中余量最小者，无则 BF；w≈0 视为可接受（正好装满不算死）。早期限 seenCount≥20。
读法：偏离率<2% ⇒ 轴在分数上不可能显形；偏离率高但箱数不降 ⇒ τ 误判或牺牲了大件唯一容量。
未验假设：活块一定能被吃掉；双峰里小件供不应求时活块残留 ⇒ 模型高估收益 ⇒ 必须报「活块残留总量」。

## 自检计数器
触发率<2% ⇒ 轴在分数上不可能显形。翻转分三类：箱数不同 / 箱数同但选件集合不同 / 完全相同（未触发），第三类单独报。归因按「箱数下降」计，不按内部价值函数上升计。第四个计数：活块残留总量、死块数；「箱数同但余量剖面不同」的实例数 = 下一代候选池。触发率是逐实例确定性计数 ⇒ 零成本、不受运行噪声影响；只有终点箱数需 bootstrap。

## 噪声地板
同代码两次跑结果不同。D_null 的实例级 bootstrap 区间须分离。报 N、半宽、最小可检测效应；半宽>待检效应 ⇒ 无分辨力。σ 臂须引擎统一跑并给实例级配对数据；区间用配对差算，不是两个均值的差。

## 可复用度量（跨域，来自 #582）
改候选表前先量「候选召回率」：|旧表∩新表|/旧表大小，逐实例报均值/5 分位/低于阈值的实例占比。口径：分母用两边有效槽位 min(|KNN|,|QNN_eff|)，另报「QNN 独有候选数」；预算归因用每轮实际评估候选数，不用名义槽位比。
