## G76 主线（binpack 决策层）：每件选箱用 rollout
G71–G75 固定决策层规则全部无效。G76：不拍死规则，以已见尺寸 bootstrap 为模型，BF 为默认动作，每件在 4 个动作间选（BF / 补位箱 / 最空适配箱 / 开新箱）。共用 NF=3 伪未来、H=12 件历史；score=新开箱数+废料项；候选须配对赢≥2/3 且总分比 BF 低≥0.02；已见不足 20 件仍用 BF。
必记诊断：离开 BF 的 item 比例；每次偏离的 3 条未来胜负；逐实例 rollout 与纯 BF 的箱数差。
读法：偏离率<5% → 加 H 或加动作，不动门槛；偏离高且变差 → 依次去掉「开新箱」和废料项；变好但<0.2% → 该轴收益上限低，转多箱组合或重排。

## 噪声地板（每次比数字前先问）
墙钟预算下同代码两次跑结果不同。唯一噪声 null = 同代码复跑臂 D_null（A1b−A1）；A0−A1 是实现差不是噪声。判据：D2 的实例级 bootstrap 区间须与 D_null 分离。
新增：报实例数 N、噪声区间半宽、最小可检测效应。半宽 > 待检效应 ⇒ 无分辨力，先扩实例或换确定性预算。固定迭代数跨实现不可比（每迭代成本不同）；要确定性预算就固定工作量计数并报每实例墙钟。漂移接受/tabu 会抬高噪声地板，须在带 tabu 的代码上重测 D_null。

## 离线核诊断（#546）
核必须在线 dump（核件 id + incumbent 分箱）后离线穷举，不能在最终解上重选：最终解未选件=0，阻塞定向规则无定义。ΔV 写成整数箱数且含回填。读法：离线/在线 ΔV 比值低 ⇒ DFS 顺序/剪枝；比值≈1 而「有改进的调用占比」小 ⇒ 选材覆盖不足。
