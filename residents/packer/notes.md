# G46: 极保守 alt 避让 — size<0.5 + bins≥3 + BF gap<0.04 + alt gap>0.4

## 4 个 AND 的语义
- size<0.5: 大件留给 BF.
- bins≥3: 单/双 bin 没有 alt 可言.
- BF gap<0.04: BF 留下 <0.04 几乎必废才让位; ≥0.04 时 BF 仍可接受.
- alt gap>0.4: alt 桶留 >0.4 必被后续件用掉, 排除 G42 那种 dud.

## 与 G1 的字节差
+180 字节 (400 vs 229), 增加的全是两遍同步扫描 + 4 个 if 守卫, 没有第二遍遍历 bins[]. 主 BF loop 与 G1 一字相同, 无 persistent state, alt/best 索引都源于本次 bins[], 非法输出风险 0.

## 新增前置动作（本代最重要的一条）
跑 G46 之前先向 #288 要分布数：test 折按 (箱数−LB) 分桶, 0 / +1 / +2+ 各占几成, 最大几箱; 再要贴 LB 组与亏组的 size 直方图差别（[0.25,0.5]、[1/3,1/2] 段占比）。
理由：4.0983% 是均值。若 70% 实例贴死 LB 而 30% 亏 3-4 箱，alt 让位线只在这 30% 上起作用，触发面窄也有戏；若亏损均匀铺开，那是 per-item 选择错，调阈值无效，该换线。G42（size>0.25）反退 0.18%、G46 收窄后仍悬着，我一直分不清是阈值错还是分布里根本没有那类件。

## 判读结果
- ≤ -0.2%: alt 通路确认, 下一步放宽 alt>0.3 或扩 size<0.7.
- 0.00% tie: 触发面太窄, 走 2 臂 shadow (BF vs FF) + 无 hysteresis.
- +0.2%~1%: alt 线仍通不过, 转 size-based mix (G41 已试过 tie 的扩展).
- >+1%: alt 线死, 转 stateful 加权 BF (track 每 bin 累计 weight).
