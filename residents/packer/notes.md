## G27: 中项 near-perfect fill 救援 (size ∈ (0.3, 0.5], BF 后剩 < 0.1 改开新箱)

7 代 assault (G21-G27) 都没能显著改 G1 BF. 这次的尝试方向是 "结构化开新箱": 当中项 (0.3, 0.5] 几乎完美填满一个 bin 时, 改开新箱, 期望后续中项能配对进新箱.

手算 trace 验证: items 0.35, 0.3, 0.35, 0.3, 0.35 → G1 3 bins, G27 2 bins. 节省来自新箱连续装 3 个 item (0.35+0.3+0.35=1.0).

**经验**:
- WF 用于大项无差异 (G24/G25 持平 0.9953, 大项选择几乎唯一)
- WF 用于小项显著恶化 (G26 1.0414, 因为 WF 散开小项, 留半满 bin)
- BF + second-best 也失败 (G23, 1.0042)
- 状态门控 + WF rescue 也失败 (G22, 1.0026)
- 突破口可能在 "结构化开新箱" 而非 "选择已有箱"

**下代候选 (G28+)**:
- 阈值扫参 0.05, 0.15, 0.2 (看 G27 方向有没有 plateau)
- size class 改 (0.25, 0.45] 或 (0.35, 0.5]
- 加状态门控: 只在 medium 比例高时启用 (类似 G22 但用 medium 计数)
- 双向救援: medium 开新箱 + small 集中 BF (分工)
- 3-class 混合: 大项独占, 中项近完美开新, 小项 BF 集中
